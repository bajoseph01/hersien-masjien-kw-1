# Hersien-Masjien kw-1

Grade 6 Afrikaans revision: meervoude, verkleinwoorde and geslag.

Class link: https://bajoseph01.github.io/hersien-masjien-kw-1/

No API key or learner login is required. Internet access is needed for Tailwind styling and Google Fonts.

To publish updates, run `node node_modules/vite/bin/vite.js build`, then commit and push the source and `docs/` folder. GitHub Pages publishes `docs/` from `main`.
